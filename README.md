PROJECT VERITAS

A 4-Bit Forensic Engine for Information Integrity

The Catalyst

In December 2024, the news reporting on Luigi Mangione hit a "Narrative G-Force" that effectively erased the physical telemetry of the case—specifically the 48-hour spatial gap between NY and PA. Project Veritas was built to identify when a story transitions from Signal to Stain.

The Architecture

Veritas uses a heterogeneous approach adapted from Project Sovereign:

Executive Sentry (C++): A low-level gatekeeper that manages the I/O and scans for "Linguistic Glitter" (noise words).

Cognitive Brain (Python): A logic layer that quantizes news into a 4-bit (0-15) scale.

The Sink State (Markov Logic): When narrative noise exceeds a threshold, the system enters the Emergency State. This state is locked, representing a "Permanent Stain" where the original truth is no longer recoverable.

The Mission

To restore Independence of Thought. We don't tell you what to believe; we tell you when you are being programmed.
